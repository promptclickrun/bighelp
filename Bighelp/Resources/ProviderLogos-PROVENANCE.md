## Remote raster distribution

The app's vector assets above remain the bundled offline fallback. The separate
provider-logo publisher renders those approved sources to transparent PNGs for
native network loading, with a maximum dimension of 512 pixels and the original
canvas proportions. It does not recolor, crop, stretch or replace the bundled
source vectors. These PNGs are rendering derivatives, not byte-identical copies
of the source SVGs; the published manifest records each PNG's own SHA-256 digest.

The public static distribution includes `ProviderLogos-NOTICES.txt`. Source
selection, variant restrictions and the existing app-side presentation policy
remain unchanged. See `services/provider-logos/README.md` at the repository root
for the export, verification and independently authorized publishing procedure.
