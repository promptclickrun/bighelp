# Third-party notices

Loopdy AI depends on open-source JavaScript, Swift, Objective-C, and Python software. Dependency names and resolved versions are recorded in `pnpm-lock.yaml`, `apps/mobile/ios/Podfile.lock`, and the relevant package manifests.

Each dependency remains subject to its own license and attribution requirements. Before redistributing binaries, generate a dependency license report for the exact resolved build, review copyleft and attribution obligations, and ship the required license texts with that distribution.

Dependencies requiring particular review include `caniuse-lite` data (`CC-BY-4.0`), `lightningcss` (`MPL-2.0`), and `react-native-fit-image` (`Beerware`). These are transitive dependencies and retain their upstream terms.

The Apache-2.0 license in [LICENSE](LICENSE) applies to first-party source in this repository unless a file states otherwise.
